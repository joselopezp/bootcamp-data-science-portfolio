# data/raw

Intermediate files generated by the notebook. They are not versioned.

- Lessons 1-2 regenerate the `.npy` arrays and `customers_preliminary.csv` / `transactions_preliminary.csv` (seeded).
- Lesson 3 reads two inputs, `shopify_orders_2024.xlsx` and `marketing_metrics.html`, which were created outside the notebook and were not preserved.
  Consequently `transactions_consolidated.csv` and `transactions_cleaned.csv` (Lessons 3-4) cannot be regenerated.
- The final datasets produced by the original run are published in `data/processed/`.
